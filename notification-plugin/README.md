# EaglerNotifications

Velocity plugin for sending notification badges through EaglerXServer 1.1.1.

Build with `gradle build` after placing `EaglerXServer.jar` in `../bungee/plugins/`.
The generated jar is `build/libs/EaglerNotifications-1.0.0.jar`.

The proxy command is `/eaglernotify <message>` or `/eaglernotify <title> :: <message>`.
It requires the `eaglernotifications.send` permission.
